## 任务

读取同目录下的 `sales.csv`，完成下面 4 件事：

### 1. 读文件
文件格式：`日期,产品,数量,单价`

第一行是表头，从第二行开始才是数据。

### 2. 统计总销售额

```
总销售额 = 每一行的（数量 × 单价）之和
```

### 3. 按产品汇总

算出每个产品各自的销售额，例如：

```
拿铁: 22.5*3 + 22.5*1 + ...
```

### 4. 找出销售额最高的产品

### 5. 输出

先打印到屏幕，再写入同目录的 `result.json`，格式：

```json
{
  "总销售额": 1234.5,
  "订单数": 20,
  "产品销售额": {
    "拿铁": 400.5,
    "美式": 320.0
  },
  "最高产品": "拿铁"
}
```

金额保留 1 位小数。

## 提示（卡住才看，看一次扣 10 分钟）

<details>
<summary>提示 1：怎么读文件</summary>

```python
with open("sales.csv", encoding="utf-8") as f:
    lines = f.readlines()
```
读取后每行末尾有换行符，用 `.strip()` 去掉。

</details>

<details>
<summary>提示 2：怎么拆每一行</summary>

```python
parts = line.split(",")
# parts[0] 日期, parts[1] 产品, parts[2] 数量, parts[3] 单价
```

注意：拆出来的是**字符串**，数字要 `int()` / `float()` 转换。

</details>

<details>
<summary>提示 3：怎么按产品累加</summary>

字典累加的标准写法：

```python
totals = {}
totals[p] = totals.get(p, 0) + 金额
```
`dict.get(键, 默认值)` 表示"有就取出来，没有就当 0"。

</details>

<details>
<summary>提示 4：怎么输出 JSON</summary>

```python
import json
with open("result.json", "w", encoding="utf-8") as f:
    json.dump(结果, f, ensure_ascii=False, indent=2)
```
`ensure_ascii=False` 才能让中文正常显示。

</details>
